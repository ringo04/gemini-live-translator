# Gemini Live API リアルタイム翻訳アプリ

このプロジェクトは、Googleの **Gemini Live API (Live Translate)** と通常の **Gemini API (Generate Content)** を組み合わせた、iOS向けのリアルタイム翻訳・フレーズ学習アプリです。

マイクに入力された音声（例: スピーチや会話）をリアルタイムに翻訳してスピーカーから再生し、タイムライン上のテキスト（翻訳・文字起こし）から気になる単語をタップすることで、その単語の「解説カード」を即座に生成・表示します。

---

## ✨ 主な機能

- **リアルタイム音声翻訳**: 音声入力をリアルタイムでテキスト化・翻訳し、合成音声をスピーカーから再生。
- **インタラクティブテキスト**: タイムラインに流れるテキストは単語ごとにタップ可能。
- **スマート原形抽出**: 単語がタップされると、`NLTagger` が自動で品詞や原形（例: 「行きました」→「行く」、「統合している」→「統合」）を解析し、適切な単語で解説をリクエストします。
- **Gemini API 単語解説**: タップした単語の品詞、意味、発音記号、ニュアンス、例文、および例文の対訳を記載したカードをリアルタイムに生成してアコーディオン表示。
- **翻訳履歴の保存**: 会話セッションごとのテキストを履歴としてローカルに保存し、後から見返すことが可能。
- **セキュアなAPIキー管理**: APIキーは iOS の Keychain に安全に保存されます。

## 📂 ファイル構成

1. **`ContentView.swift`**: アプリのルートUI。メインの画面遷移や状態管理を統括。
2. **`GeminiLiveTranslator.swift`**: WebSocketによるリアルタイム翻訳ストリーム処理と、`AVAudioEngine` によるマイク入力/音声合成再生。
3. **`KeywordExtractor.swift`**: タップされた単語を `NLTagger` で原形化し、Gemini API (`gemini-2.5-flash`) を呼び出して解説データをJSON形式で取得するロジック。
4. **`MainTimelineView.swift`**: 翻訳・文字起こし結果をタイムライン形式で表示。単語タップのハンドリングや、発話ボリュームに連動する美しいアニメーションを実装。
5. **`KeywordExplanationViews.swift`**: 取得した単語解説カードをスライドイン・アコーディオン形式で表示するUI。
6. **`SavedContentViews.swift`**: 保存された過去の翻訳セッション一覧と詳細表示。
7. **`APIKeyPromptView.swift`**: 初回起動時の Gemini API キー入力画面と有効性検証。
8. **`SettingsViews.swift`**: APIキーの再設定やリセットを行う設定画面。
9. **`KeychainStorage.swift`**: APIキーをセキュアに保持するヘルパー。
10. **`Components.swift`**: UIスタイル（ConcentricRectangle等）や、言語コードの拡張ロジック。

## 🎙️ 操作方法

1. アプリを実機またはシミュレータでビルドし、起動します。
2. 画面に **Gemini API Key** の入力フィールドが表示されるので、Google AI Studio で取得したキーを入力して「保存」します。
3. 翻訳先のターゲット言語を選択します（例: `日本語`）。
4. **「接続開始」** ボタン（マイクアイコン）をタップして、WebSocket接続を確立します（ステータスが「接続中」になれば成功です）。
5. **「マイク開始」** をタップして、マイクに向かって話しかけてください。
6. 話した音声の書き起こし、および翻訳された言語がリアルタイムに表示され、翻訳音声がスピーカーから再生されます。
7. タイムライン上の単語をタップすると、その単語の解説カードが画面下部に表示されます。カードをタップすると、発音記号や品詞、例文が展開されます。
